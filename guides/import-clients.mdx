# Import Clients from CSV

Already have a client list in a spreadsheet? Import them into FORGE in just a few clicks.

## Preparing Your CSV

Your CSV file should have columns for client information. Common columns:

| Column | Example |
|--------|---------|
| Name | John Smith |
| Email | john@email.com |
| Phone | (555) 123-4567 |
| Tags | VIP, Family |
| Notes | Prefers window seats |

<Tip>
The first row should be column headers. FORGE will use these to map your data.
</Tip>

## Importing

1. Go to **CRM** section
2. Click **Import**
3. Drag and drop your CSV file (or click to browse)
4. FORGE shows your columns and sample data

## Mapping Columns

For each column in your CSV:

1. Select which FORGE field it maps to
2. Available fields: Name, Email, Phone, Tags, Notes
3. Leave unmapped columns as "Skip"

<Info>
**Name is required.** All other fields are optional.
</Info>

## Preview & Confirm

Before importing:

1. Review the preview showing how data will be imported
2. Check for any duplicates (FORGE warns if emails already exist)
3. Click **Import Clients**

## After Import

Once imported:

- Clients appear in your CRM list
- You can edit any client to add more details
- Start linking trips and adding notes

## Tips

<Tip>
Export from your existing CRM or spreadsheet as CSV (comma-separated values) for best compatibility.
</Tip>

<Warning>
Large imports (500+ clients) may take a moment to process.
</Warning>
