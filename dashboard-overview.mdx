# Dashboard Overview

When you log in to FORGE, you'll see the main dashboard with three panels.

## Left Sidebar — Navigation

The left sidebar contains all main sections:

| Section | Purpose |
|---------|---------|
| **Builder** | Upload screenshots, extract trip details with AI |
| **Options** | Your library of saved trip options |
| **Compare** | Create and manage client comparisons |
| **Itinerary** | Build day-by-day trip itineraries |
| **CRM** | Manage client contacts and notes |
| **Payments** | Request and track planning fees |
| **Settings** | Your profile, branding, and preferences |

## Middle Panel — Lists

The middle panel shows items for the selected section:
- Trip options in your library
- Active comparisons
- Client list
- Payment history

Click any item to open it in the detail panel.

## Right Panel — Details

The right panel shows the full details of whatever you've selected:
- Edit trip option details
- Customize comparison settings
- View client history
- Manage itinerary days

## Tips

<Tip>
Use the **search bar** at the top of the middle panel to quickly find options, comparisons, or clients.
</Tip>

<Tip>
The **?** button next to each section title opens a quick help guide for that feature.
</Tip>
