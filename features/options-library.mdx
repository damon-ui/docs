# Options Library

The Options Library stores all the trip options you've created or extracted. Think of it as your inventory of trips ready to present to clients.

## Viewing Options

- Click **Options** in the left sidebar
- Use the search bar to filter by client name, destination, or trip type
- Click any option to view and edit its details

## Editing an Option

Select an option to open the detail editor where you can:

- Update pricing (per person, deposits, totals)
- Edit dates and duration
- Modify cabin/room categories
- Add or remove inclusions
- Update vendor information
- Add notes

<Info>
  Changes are not saved automatically, be sure to hit "Save" frequently!!
</Info>

## Creating Comparisons

To create a comparison from your options:

1. Check the boxes next to 2-3 options you want to compare
2. Click **Create Comparison** in the toolbar
3. Give it a title and customize as needed

<Tip>
  You can select up to 3 options for a single comparison. This keeps client decisions manageable.
</Tip>

## Creating Itineraries

To create an itinerary from an option:

1. Click the **calendar icon** on any option card
2. FORGE creates a new itinerary with the trip dates pre-filled
3. Add day-by-day activities and details

## Deleting Options

1. Select the option(s) you want to delete
2. Click **Delete** in the toolbar
3. Confirm the deletion

<Warning>
  Deleting an option removes it permanently. It won't affect comparisons that already include it.
</Warning>
